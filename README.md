# Bible Projector

PWA-система для вывода библейских стихов, песен и заметок на экран или
проектор. Пульт оператора и экран трансляции работают в отдельных окнах,
без аккаунта и без сервера.

Стабильная версия: **2.2.0**

Новая линия разработки: **3.0.0-preview.1**

## Возможности

- **4 перевода Библии:** Синодальный (RST), Новый Русский (NRT),
  казахский (KTB) и кыргызский (KYB).
- **Поиск по ссылке и тексту:** поддерживаются русские, казахские и
  кыргызские названия и сокращения книг.
- **Каталог песен:** полнотекстовый поиск и отдельные слайды для куплетов,
  припевов и бриджей.
- **Порядок служения:** список стихов, песен и заметок с перестановкой,
  локальным сохранением, импортом и экспортом JSON.
- **Библиотека:** песни, Библия и история трансляций в одной боковой панели.
- **Экран проектора:** отдельное окно, быстрый показ, скрытие и настройки
  оформления.
- **PWA и офлайн-режим:** приложение устанавливается на компьютер и после
  первого запуска работает без интернета.
- **Адаптивный интерфейс:** боковые панели сворачиваются на компьютере и
  открываются поверх контента на узких экранах.

## Быстрый старт

### Онлайн

1. Откройте [приложение](https://bibleprojector.kz/app/controller.html) в Chrome.
2. При необходимости установите его через кнопку в адресной строке.
3. Нажмите кнопку с монитором, чтобы открыть экран проектора.

### Локально

Для корректной работы ES-модулей и Service Worker запускайте проект через
локальный HTTP-сервер:

```bash
git clone https://github.com/Sherzattv/bibleprojector.git
cd bibleprojector
python3 -m http.server 8080
```

Затем откройте
`http://localhost:8080/app/controller.html`.

## Управление

| Действие | Клавиша |
| --- | --- |
| Найти стих по ссылке | `Enter` |
| Отправить предпросмотр в эфир | `Ctrl + Enter` |
| Скрыть содержимое с экрана | `Esc` |
| Предыдущий или следующий стих/слайд | `↑` / `↓` |
| Свернуть порядок служения | `F2` |
| Свернуть библиотеку | `F4` |
| Полноэкранный режим окна проектора | `F11` |

## Разработка и проверка

Требуется Node.js 18 или новее.

```bash
npm ci
npm test
npm run lint
npm run verify:layout
```

- `npm test` запускает модульные тесты Vitest.
- `npm run lint` проверяет JavaScript через ESLint.
- `npm run verify:layout` проверяет раскладку на настольных и мобильных
  разрешениях во всех состояниях боковых панелей.

### Структура проекта

```text
app/
├── controller.html    # Пульт управления
├── display.html       # Экран проектора
├── offline.html       # Страница офлайн-режима
├── manifest.json      # PWA-манифест
├── sw.js              # Service Worker
├── tests/             # Модульные тесты
├── js/
│   ├── app.js         # Логика пульта
│   ├── display.js     # Логика экрана проектора
│   ├── modules/       # Поиск, эфир, история, настройки, песни, setlist
│   └── data/          # Библии и каталог песен
└── icons/             # Иконки приложения
```

Лендинг и страницы контактов находятся в корне репозитория. Развёртывание
статических файлов на Cloudflare настраивается в `wrangler.jsonc`.
