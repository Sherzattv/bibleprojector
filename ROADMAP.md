# Roadmap Bible Projector v3

Актуально для **3.0.1** на 12 августа 2026 года.

v3 — единственная кодовая база приложения. Runtime и UI v2 удалены;
отдельного продуктового roadmap у них нет.

## Текущий фокус

UX-полировка Omnibox и проекционного текста завершена (стрелки, ARIA,
autofit, контраст, автопрокрутка). Работа продолжается в таком порядке:

1. E2E раскладки на поддерживаемых desktop-разрешениях.
2. Первый онлайн-запуск и повторный полностью офлайн-запуск.
3. Автопереоткрытие окна проектора при подключении монитора.
4. Предупреждение оператору об экстремально длинном тексте (autofit уже
   уменьшает его автоматически).

## Критерии стабильного релиза

- [ ] Основные сценарии служения покрыты браузерными E2E-тестами.
- [ ] Пульт проверен без переполнения на поддерживаемых desktop-разрешениях.
- [x] Длинный текст автоматически помещается на экран без обрезания.
- [x] Можно выбрать, запомнить и повторно открыть нужный внешний монитор.
- [x] Пульт умеет запросить fullscreen и закрыть окно проектора.
- [x] Omnibox поддерживает стрелки, активный результат и ARIA combobox.
- [ ] Проверен первый онлайн-запуск и повторный полностью офлайн-запуск.
- [ ] Проведено полевое тестирование на реальном служении.
- [x] Лендинг на корневом URL, приложение на `/app/` со своим PWA scope
  (временный `/next/` удалён).
- [x] Раздача статики зафиксирована дымовым тестом в CI: регрессия
  `html_handling`/`not_found_handling` больше не проходит молча.
- [ ] Проверены и зафиксированы риски dev-зависимостей PWA.

## Ближайший приоритет

### 1. Браузерные сценарии

- [x] Поиск точной ссылки → Preview → GO → история.
- [x] Поиск и показ песни с несколькими секциями.
- [x] Создание, сохранение, экспорт и импорт порядка.
- [x] Перезагрузка с восстановлением порядка, истории и настроек.
- [x] Подключение и потеря окна проектора.
- [x] Закрытие окна кнопкой пульта; «Очистить» окно не трогает.
- [ ] Desktop `1280×720`, `1366×768`, `1440×900` и `1920×1080` без
  горизонтального переполнения и перекрытия рабочих панелей.
- [ ] Первый запуск, обновление данных и офлайн-fallback.

### 2. Полное управление проектором

- [x] Выбор экрана в шапке пульта поверх автоподбора первого внешнего.
- [x] Сохранение выбранного экрана: label, размер и позиция, с откатом
  по каждому признаку при смене раскладки мониторов.
- [x] Обработка `screenschange`.
- [x] Запрос fullscreen на выбранном экране с честной подсказкой на самом
  экране, когда автоматически не вышло.
- [x] Закрытие и повторное открытие окна из пульта.
- [x] Понятное состояние popup blocked (permission denied намеренно молчит:
  окно всё равно открывается, оператор перетащит его сам).
- [ ] Автопереоткрытие окна проектора, когда монитор подключили посреди
  служения (сейчас список обновляется, но окно открывает оператор).

### 3. Проекционный текст

- [x] Autofit по количеству строк и длине текста (превью и экран).
- [ ] Предупреждение оператору, если текст ужат до минимального масштаба.
- [ ] Проверка стихов, песен и заметок на экране проектора 16:9 и 4:3.

### 4. Omnibox и доступность

- [x] Навигация по результатам стрелками.
- [x] Выделенный активный результат и Enter по нему.
- [x] ARIA combobox/listbox с `aria-activedescendant`.
- [x] Выбор мышью по `pointerdown` — без гонки с blur-таймером.
- [x] Контраст вторичных подписей на уровне WCAG AA (страж-тест в CI).
- [x] Автопрокрутка активного слайда в видимую область.
