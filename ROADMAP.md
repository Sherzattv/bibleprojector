# Roadmap Bible Projector v3

Актуально для **3.0.0-preview.1** на 25 июля 2026 года.

v3 — единственная кодовая база приложения. Runtime и UI v2 удалены;
отдельного продуктового roadmap у них нет.

## Текущий фокус

Сейчас приоритет — UX-полировка desktop-интерфейса оператора без расширения
поддерживаемых платформ. Конкретные UX-изменения должны сохранять рабочие
сценарии Preview, Live, поиска, порядка и отдельного окна проектора.

После UX-полировки работа продолжается в таком порядке:

1. E2E раскладки на поддерживаемых desktop-разрешениях.
2. Первый онлайн-запуск и повторный полностью офлайн-запуск.
3. Выбор внешнего монитора и полное управление окном проектора.
4. Autofit и предупреждение об обрезании длинного проекционного текста.

## Критерии стабильного 3.0.0

- [ ] Основные сценарии служения покрыты браузерными E2E-тестами.
- [ ] Пульт проверен без переполнения на поддерживаемых desktop-разрешениях.
- [ ] Длинный текст автоматически помещается на экран без обрезания.
- [ ] Можно выбрать, запомнить и повторно открыть нужный внешний монитор.
- [ ] Пульт умеет запросить fullscreen и закрыть окно проектора.
- [ ] Omnibox поддерживает стрелки, активный результат и ARIA combobox.
- [ ] Проверен первый онлайн-запуск и повторный полностью офлайн-запуск.
- [ ] Проведено полевое тестирование на реальном служении.
- [x] v3 перенесена с `/next/` на основной URL с корневым PWA scope.
- [ ] Проверены и зафиксированы риски dev-зависимостей PWA.

## Ближайший приоритет

### 1. Браузерные сценарии

- [x] Поиск точной ссылки → Preview → GO → история.
- [x] Поиск и показ песни с несколькими секциями.
- [x] Создание, сохранение, экспорт и импорт порядка.
- [x] Перезагрузка с восстановлением порядка, истории и настроек.
- [x] Подключение и потеря окна проектора.
- [ ] Desktop `1280×720`, `1366×768`, `1440×900` и `1920×1080` без
  горизонтального переполнения и перекрытия рабочих панелей.
- [ ] Первый запуск, обновление данных и офлайн-fallback.

### 2. Полное управление проектором

- [ ] Диалог выбора экрана вместо автоматического первого внешнего.
- [ ] Сохранение устойчивого идентификатора/label выбранного экрана.
- [ ] Обработка `screenschange`.
- [ ] Запрос fullscreen на выбранном экране.
- [ ] Закрытие и повторное открытие окна из пульта.
- [ ] Понятные состояния permission denied и popup blocked.

### 3. Проекционный текст

- [ ] Autofit по доступной области, количеству строк и длине текста.
- [ ] Предупреждение оператору, если текст не помещается.
- [ ] Проверка стихов, песен и заметок на экране проектора 16:9 и 4:3.

### 4. Omnibox и доступность

- [ ] Навигация по результатам стрелками.
- [ ] Выделенный активный результат и Enter по нему.
- [ ] ARIA combobox/listbox.
- [ ] Убрать зависимость выбора мышью от blur-таймера.
- [ ] Поднять контраст вторичных подписей до WCAG AA.
- [ ] Автопрокрутка активного слайда в видимую область.
