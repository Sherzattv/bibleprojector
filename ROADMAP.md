# Roadmap: Bible Projector

Актуально для стабильной версии **2.2.0** и preview
**3.0.0-preview.1** на 25 июля 2026 года.

## Bible Projector v3

- [x] Svelte 5, TypeScript, Vite и новая дизайн-система.
- [x] Единый поиск ссылок, текста Библии и песен.
- [x] Поиск в Web Worker.
- [x] Preview/Live и отдельное окно проектора.
- [x] PWA и версионированный офлайн-кэш данных.
- [x] Сохраняемый порядок служения, заметки, импорт и экспорт.
- [x] Сохраняемая история эфира.
- [x] Адаптивные панели для планшетов и телефонов.
- [ ] Браузерные E2E-тесты основных сценариев служения.
- [ ] Автоподбор размера текста и дополнительные темы.
- [ ] Полное управление выбранным внешним экраном.
- [ ] Миграция v3 на основной URL после полевого тестирования.

## В работе и далее

### Высокий приоритет

- [ ] **Параллельный перевод**
  - Подключить существующий поиск по нескольким переводам к интерфейсу.
  - Добавить выбор основного и дополнительного перевода.
  - Вывести два текста рядом или друг над другом на экране трансляции.

- [ ] **Единый умный поиск**
  - [x] Объединить поиск по ссылке, тексту Библии и песням в одном поле v3.
  - [x] Автоматически определять тип запроса.
  - [ ] Добавить полноценную навигацию стрелками по результатам.

- [ ] **Полное управление экраном трансляции**
  - [x] Открыть окно проектора.
  - [x] Скрыть текущее содержимое.
  - [x] Включить отдельный режим затемнения в v3.
  - [ ] Запросить полноэкранный режим.
  - [ ] Закрыть окно проектора из пульта.

### Следующий приоритет

- [x] **Навигация по книгам**
  - В v3 добавлен визуальный выбор книги и главы.

- [ ] **Дополнительные темы**
