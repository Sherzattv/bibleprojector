# Roadmap Bible Projector v3

Актуально для **3.0.0-preview.1** на 25 июля 2026 года.

v3 — единственная активная линия разработки. Версия 2.2.0 в `app/`
заморожена как legacy и не имеет отдельного продуктового roadmap.

## Критерии стабильного 3.0.0

- [ ] Основные сценарии служения покрыты браузерными E2E-тестами.
- [ ] Длинный текст автоматически помещается на экран без обрезания.
- [ ] Можно выбрать, запомнить и повторно открыть нужный внешний монитор.
- [ ] Пульт умеет запросить fullscreen и закрыть окно проектора.
- [ ] Omnibox поддерживает стрелки, активный результат и ARIA combobox.
- [ ] Проверен первый онлайн-запуск и повторный полностью офлайн-запуск.
- [ ] Проведено полевое тестирование на реальном служении.
- [ ] Подготовлена миграция v3 с `/next/` на основной URL и PWA scope.
- [ ] Проверены и зафиксированы риски dev-зависимостей PWA.

## Ближайший приоритет

### 1. Браузерные сценарии

- [x] Поиск точной ссылки → Preview → GO → история.
- [x] Поиск и показ песни с несколькими секциями.
- [ ] Создание, сохранение, экспорт и импорт порядка.
- [ ] Перезагрузка с восстановлением порядка, истории и настроек.
- [ ] Подключение и потеря окна проектора.
- [ ] Desktop, планшет и телефон без выхода за экран.
- [ ] Первый запуск, обновление данных и офлайн-fallback.

### 2. Полное управление проектором

- [ ] Диалог выбора экрана вместо автоматического первого внешнего.
- [ ] Сохранение устойчивого идентификатора/label выбранного экрана.
- [ ] Обработка `screenschange`.
- [ ] Запрос fullscreen на выбранном экране.
- [ ] Закрытие и повторное открытие окна из пульта.
- [ ] Понятные состояния permission denied и popup blocked.

### 3. Проекционный текст

- [ ] Autofit по доступной области, количеству строк и длине текста.
- [ ] Предупреждение оператору, если текст не помещается.
- [ ] Проверка стихов, песен и заметок на 16:9, 4:3 и portrait.

### 4. Omnibox и доступность

- [ ] Навигация по результатам стрелками.
- [ ] Выделенный активный результат и Enter по нему.
- [ ] ARIA combobox/listbox.
- [ ] Убрать зависимость выбора мышью от blur-таймера.
- [ ] Поднять контраст вторичных подписей до WCAG AA.
- [ ] Увеличить критичные touch-таргеты.
- [ ] Автопрокрутка активного слайда в видимую область.

## Следующий приоритет

### Параллельные переводы

- [ ] Выбор основного и дополнительного перевода.
- [ ] Синхронизация по canonical code, главе и VerseId.
- [ ] Раскладка рядом или друг над другом.
- [ ] Поведение при отсутствующем стихе во втором переводе.

### Темы и служебные экраны

- [ ] Рабочая кнопка логотипа.
- [ ] Настраиваемый фон и логотип общины.
- [ ] Дополнительные темы проекционного экрана.
- [ ] Плавные, но отключаемые переходы.

### Снижение legacy-зависимости

- [ ] Перенести `canonical`, `parseQuery` и `splitSongSections` в TypeScript.
- [ ] Удалить дублирующий неиспользуемый legacy-код.
- [ ] Оставить `app/js/data/` только источником для конвертера.
- [ ] После релиза 3.0.0 определить срок удаления runtime v2.

## Уже реализовано в v3

- [x] Svelte 5, TypeScript, Vite и Tailwind CSS 4.
- [x] Единая дизайн-система.
- [x] Четыре перевода и каталог из 11 524 песен.
- [x] Единый поиск ссылок, текста Библии и песен.
- [x] MiniSearch в Web Worker с debounce.
- [x] Preview/Live, сетка слайдов и слой команд.
- [x] Отдельное окно проектора и честный connected-статус.
- [x] Window Management API с fallback на popup.
- [x] Wake Lock и fullscreen по двойному клику.
- [x] Blackout, заметки, правки текста и настройки проекции.
- [x] Сохраняемый порядок с импортом, экспортом и миграцией v2.
- [x] Сохраняемая история эфира.
- [x] PWA и версионированный офлайн-кэш данных.
- [x] Очистка и валидация данных при конвертации.
- [x] Адаптивные панели для планшетов и телефонов.
- [x] Строгая проверка Svelte/TypeScript в CI.
- [x] 234 модульных теста.
- [x] Chromium E2E для точной ссылки и многосекционной песни: Preview,
  Live, история и восстановление порядка после перезагрузки.
