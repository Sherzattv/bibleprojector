# Дизайн-система Bible Projector 3.0

Все значения — только из этих шкал. Произвольные `text-[..px]` / `p-[..px]`
в компонентах запрещены (исключение — проекционные экраны с `clamp()`).

## Поддерживаемая платформа

- Пульт оператора проектируется для desktop Chromium.
- Минимальное поддерживаемое окно пульта — `1280×720`.
- Контрольные размеры: `1280×720`, `1366×768`, `1440×900`, `1920×1080`.
- Планшеты и телефоны не входят в продуктовый и тестовый scope.
- Выдвижные панели на узких окнах остаются аварийным fallback без гарантии
  полной работоспособности.
- Экран проектора проверяется отдельно в форматах 16:9 и 4:3.

## Типографика (5 ступеней)

| Токен       | Размер/интерлиньяж | Использование                                  |
| ----------- | ------------------ | ---------------------------------------------- |
| `text-2xs`  | 10 / 14            | микро-подписи слайдов, kbd                     |
| `text-xs`   | 11 / 16            | метаданные, статус-строки, заголовки колонок   |
| `text-sm`   | 12 / 16            | вторичный UI: кнопки, вкладки, поле поиска     |
| `text-base` | 13 / 20            | основной UI: строки списков, названия          |
| `text-lg`   | 14 / 20            | заголовки панелей (название песни)             |

Правила:
- Жирность: 400 обычный, 500 названия/кнопки, 600 заголовки. 700 — только GO.
- Uppercase допустим только на `text-xs`/`text-2xs` и всегда с `tracking-wide`.
- Цифры в колонках — `font-mono tabular-nums`.

## Отступы — сетка 4px

Только шаги Tailwind: `0.5`(2) `1`(4) `1.5`(6) `2`(8) `3`(12) `4`(16) `6`(24).
Горизонтальный паддинг всех панелей — `px-3` (12). Ряды списков — `px-3 py-1.5`.

## Высоты контролов

| Элемент                        | Высота        |
| ------------------------------ | ------------- |
| Верхняя панель                 | `h-12` (48)   |
| Заголовки/вкладки колонок      | `h-9` (36)    |
| Кнопки тулбара, поле поиска    | `h-7` (28)    |
| Строка статуса внизу колонок   | `h-8` (32)    |

## Радиусы — два значения

- `rounded` (4) — кнопки, инпуты, kbd, бейджи;
- `rounded-md` (6) — карточки слайдов, экраны, выпадающие панели.

## Цвет

Нейтральная тёмная шкала + один акцент (`accent`, синий).
Семантика: `live` (красный) — только эфир/blackout; `go` (зелёный) — только
кнопка GO и статус «подключено». Никаких градиентов, свечений и теней,
кроме тени у выпадающих панелей.
